# Week 4: 自动分单 + 飞书消息通知

> **执行方式:** 使用 delegate_task 子代理逐任务执行

**目标:** 新工单自动分配给负载最低的客服，并通过飞书机器人通知相关人员

---

## Task 1: 自动分单逻辑

**改动文件:**
- `main.py` — 修改工单创建端点

**分单算法:**
- 查询所有激活的客服
- 按当前 open_tickets 数量排序
- 分配给 open_tickets 最少的客服
- 如果所有客服都有 5+ 个未处理工单，保留未指派（等待主管分配）

**API 新增/修改:**
- `POST /api/tickets` — 创建时自动分配 `assigned_to`

---

## Task 2: 飞书机器人配置

**改动文件:**
- Create: `feishu_bot.py`

**步骤:**
1. 在飞书开放平台创建应用
2. 获取 App ID + App Secret
3. 启用机器人能力
4. 添加 Webhook 事件

**核心功能:**
- 发送消息到飞书群（使用飞书 Webhook 或 API）
- 消息模板：新工单通知、AI 自动回复通知

---

## Task 3: 飞书通知对接

**改动文件:**
- `main.py` — 在创建工单和 AI 自动回复时触发通知
- 系统设置中添加飞书 Webhook URL 配置

**触发时机:**
- 新工单创建 → 通知客服群
- AI 自动回复 → 通知客服群
- 工单升级 → 通知主管

**消息格式:**
```
🎫 新工单 #{ticket_id}
标题：{title}
玩家：{player_name}
优先级：{priority}
状态：{status}
```
