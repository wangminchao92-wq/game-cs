🔌 开放 API 文档

第三方网站可以通过此 API 接入游戏客服系统，实现工单提交、实时聊天等功能。

⚡ 快速开始

📋 接入步骤：
1. 在下方 API Key 管理 中创建一个 API Key
2. 在请求 Header 中带上 X-API-Key
3. 调用 REST API 创建工单 / 查询状态
4. 或使用 WebSocket 实现实时聊天
5. 或直接嵌入聊天 Widget（一行代码）

🔑 API Key 管理

API Key 用于标识第三方接入方，所有外部 API 请求都需要在 Header 中携带。

📡 REST API

所有 REST API 基础路径：https://cs.example.com/api/external/

🔐 认证方式： 所有请求需要在 HTTP Header 中携带 X-API-Key: YOUR_API_KEY
POST /api/external/tickets 创建工单

创建新的客服工单。如果玩家 ID 不存在，会自动创建玩家。

请求参数 (JSON Body)

参数类型说明
player_id 必填string玩家唯一标识
player_name 可选string玩家昵称（默认"未知玩家"）
title 必填string工单标题
description 可选string问题描述
category 可选string分类: payment/account/gameplay/bug/report/other
priority 可选string优先级: low/medium/high/urgent
language 可选string玩家语言: zh-CN/pt-BR/en/es/ja/ko 等
server 可选string游戏服务器（默认"S1"）
curl -X POST https://cs.example.com/api/external/tickets \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY" \
  -d '{
    "player_id": "USER_10001",
    "player_name": "JoãoSilva",
    "title": "Não recebi meus itens",
    "description": "Comprei 500 moedas mas não recebi.",
    "category": "payment",
    "priority": "urgent",
    "language": "pt-BR",
    "server": "S3"
  }'
import requests

resp = requests.post(
    "https://cs.example.com/api/external/tickets",
    headers={"X-API-Key": "YOUR_API_KEY"},
    json={
        "player_id": "USER_10001",
        "player_name": "JoãoSilva",
        "title": "Não recebi meus itens",
        "language": "pt-BR",
    }
)
data = resp.json()
print(data["ticket_id"])  # → "CS-20260604-XXXX"
const resp = await fetch("https://cs.example.com/api/external/tickets", {
    method: "POST",
    headers: {
        "Content-Type": "application/json",
        "X-API-Key": "YOUR_API_KEY",
    },
    body: JSON.stringify({
        player_id: "USER_10001",
        player_name: "JoãoSilva",
        title: "Não recebi meus itens",
        language: "pt-BR",
    })
});
const data = await resp.json();
console.log(data.ticket_id);

GET /api/external/tickets/{ticket_id} 查询工单详情

查询工单的详细信息，包括所有对话记录。

curl https://cs.example.com/api/external/tickets/CS-20260604-A1B2 \
  -H "X-API-Key: YOUR_API_KEY"
{
  "ticket_id": "CS-20260604-A1B2",
  "title": "Não recebi meus itens",
  "status": "in_progress",
  "messages": [{
    "sender_type": "player",
    "content": "Comprei 500 moedas..."
  }]
}
POST /api/external/tickets/{ticket_id}/messages 发送消息

向工单发送一条新消息（来自玩家）。

curl -X POST https://cs.example.com/api/external/tickets/CS-20260604-A1B2/messages \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY" \
  -d '{"content": "Ainda não recebi, quanto tempo mais?", "sender_name": "JoãoSilva"}'

💬 WebSocket 实时聊天

通过 WebSocket 实现玩家和客服之间的实时对话。

WS /ws/chat/{ticket_id} 实时聊天连接

连接方式

// 玩家连接（无需认证）
const ws = new WebSocket("wss://cs.example.com/ws/chat/CS-20260604-A1B2");

// 客服连接
const ws = new WebSocket("wss://cs.example.com/ws/chat/CS-20260604-A1B2?role=agent");

消息格式

方向类型字段
服务端 → 客户端connectedticket_id, role, player_language
服务端 → 客户端messageid, sender_type, sender_name, content, translated_content, timestamp
服务端 → 客户端new_chatticket_id, title, sender, preview (仅发给客服)
客户端 → 服务端messagetype:"message", content, sender_name
客户端 → 服务端pingtype:"ping"

JavaScript 示例

const ws = new WebSocket("wss://cs.example.com/ws/chat/CS-20260604-A1B2");

ws.onopen = () => {
    console.log("已连接");
};

ws.onmessage = (event) => {
    const data = JSON.parse(event.data);
    if (data.type === "message") {
        console.log(data.sender_name + ": " + data.content);
        if (data.translated_content) {
            console.log("🌍 翻译: " + data.translated_content);
        }
    }
};

// 发送消息
ws.send(JSON.stringify({
    type: "message",
    content: "Olá, preciso de ajuda!",
    sender_name: "JoãoSilva"
}));

🔌 嵌入聊天 Widget

最简单的接入方式 — 只需一行 HTML 代码即可在你的网站中嵌入完整的客服聊天组件。

✅ 支持自动翻译！ 设置 data-language="pt-BR"，玩家用葡萄牙语提问，客服用中文回复自动翻译。

基本用法

<!-- 在你的网站 </body> 前添加 -->
<script src="https://cs.example.com/static/chat-widget.js"
    data-api-key="YOUR_API_KEY"
    data-server="https://cs.example.com"
    data-player-id="USER_10001"
    data-player-name="JoãoSilva"
    data-language="pt-BR"
></script>

配置参数

参数说明示例
data-api-keyAPI Key（必填）"YOUR_API_KEY"
data-server客服系统地址（必填）"https://cs.example.com"
data-player-id玩家唯一ID"USER_10001"
data-player-name玩家昵称"JoãoSilva"
data-language玩家语言"pt-BR" / "zh-CN" / "en"
data-mode模式: "chat"(即聊天) / "ticket"(先填工单)"chat"

Python (Flask/Django) 集成示例

# 在渲染页面时传入玩家信息
html = f'''
<script src="https://cs.example.com/static/chat-widget.js"
    data-api-key="{API_KEY}"
    data-server="https://cs.example.com"
    data-player-id="{player.user_id}"
    data-player-name="{player.nickname}"
    data-language="{player.language}"
></script>
'''
return render_template("game.html", widget_html=html)

📋 错误码说明

HTTP 状态码说明处理方式
200请求成功-
400请求参数错误检查请求参数是否完整
401API Key 无效检查 X-API-Key Header 是否正确
404资源不存在检查工单ID/玩家ID是否正确
429请求过于频繁降低请求频率（限制 60次/分钟）
500服务器内部错误联系管理员
